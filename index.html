Introducción

Este trabajo práctico analiza los fundamentos de desarrollo de software y tecnologías web presentados en el material audiovisual asignado. El objetivo principal es comprender la interrelación entre las distintas capas de la programación y su aplicación práctica en proyectos informáticos reales.

Conceptos Fundamentales

1. HTML5

Lenguaje de marcado estándar encargado de estructurar el contenido de las páginas web mediante etiquetas semánticas.

2. CSS3

Hojas de estilo en cascada utilizadas para diseñar, dar formato, color y adaptabilidad visual (responsive design) a los sitios web.

3. JavaScript

Lenguaje de programación que aporta interactividad, dinamismo y lógica del lado del cliente a las aplicaciones web.

4. Base de Datos (SQL)

Sistema estructurado para almacenar, consultar y gestionar información persistente de manera segura y eficiente.

5. Despliegue (Hosting)

Proceso de alojar una aplicación web en servidores accesibles públicamente a través de internet.

Cuestionario Resuelto (12 Preguntas)

1. ¿Cuál es el tema principal del video? Explica de qué trata.

Trata sobre los fundamentos del desarrollo web moderno, integrando la estructura frontend con la lógica y el almacenamiento de datos.

2. ¿Qué problema o necesidad tecnológica se aborda?

La necesidad de estructurar aplicaciones web completas, funcionales, escalables y adaptables a diferentes dispositivos móviles y de escritorio.

3. ¿Cuáles son los cinco conceptos más importantes? Define cada uno.

HTML5, CSS3, JavaScript, Consultas SQL y Control de Versiones (Git), definidos por su rol esencial en el ciclo de desarrollo.

4. ¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

Editores de código como VS Code, navegadores web para pruebas, y plataformas de despliegue como Netlify o GitHub Pages.

5. ¿Qué procedimientos o pasos se explican? Preséntalos en orden.

1. Planificación de la estructura, 2. Codificación en HTML/CSS, 3. Pruebas locales de diseño responsivo, 4. Publicación en la nube.

6. ¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

Se muestra la maquetación de una barra de navegación adaptable usando media queries en CSS para ajustar el menú en celulares.

7. ¿Qué conocimientos previos son necesarios para comprender lo explicado?

Nociones básicas de informática, lógica de programación y familiaridad elemental con la sintaxis de etiquetas web.

8. ¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

Facilidad de mantenimiento, excelente velocidad de carga, compatibilidad multiplataforma y accesibilidad pública inmediata.

9. ¿Qué dificultades, errores o precauciones deben considerarse?

Errores de sintaxis en las etiquetas, falta de adaptabilidad en pantallas pequeñas y enlaces rotos en los recursos visuales.

10. ¿Cómo aplicarías lo aprendido en un proyecto informático real?

Creando páginas web institucionales o sistemas de gestión web interactivos para pequeños negocios locales.

11. ¿Qué parte del video consideras más importante y por qué?

La demostración práctica de diseño adaptable, ya que garantiza una correcta experiencia visual para cualquier usuario.

12. ¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

Aprendí a optimizar la estructura de despliegue web. Se lo explicaría a otra persona como armar los cimientos, paredes y pintura de una casa digital.
